FETIN 2026 · 2º lugar

SafeVoice

Um app de emergência para vítimas de violência doméstica que, por fora, é só um calendário menstrual.

Com 4 toques no sino, ou 3 nos botões de volume, ele manda localização e áudio para a rede de apoio pelo WhatsApp. Fui a desenvolvedora full-stack: a API em FastAPI com fila de entregas, o banco no Supabase, os gatilhos no Flutter e os testes.

Flutter · FastAPI · Supabase · WhatsApp Cloud API · GitHub Actions
